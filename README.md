# Embedded Systems Lab Experiments

This repository contains practical experiments performed as part of the **Embedded Systems Laboratory**. It includes source code, circuit designs, simulations, and observations using various embedded systems development tools.

## 🛠️ Software and Tools Used

- **Keil µVision** – Writing, compiling, and debugging embedded C programs for microcontrollers.
- **Proteus Design Suite** – Designing electronic circuits and simulating microcontroller-based systems.
- **Arduino IDE** – Writing, compiling, and uploading Arduino programs for hardware interfacing and sensor-based applications.

## 📂 Repository Contents

The repository includes:

- Embedded C programming experiments.
- Microcontroller programming and interfacing.
- Circuit design and simulation using Proteus.
- Arduino-based practical experiments.
- Sensor interfacing and data acquisition.
- Health monitoring node programs.
- Source code, outputs, observations, and results.

## 💻 Technologies Used

- Embedded C
- Arduino Programming
- Microcontroller Systems
- Sensor Interfacing
- I²C Communication
- Digital Input/Output
- Circuit Simulation

## 🎯 Objectives

- Understand the fundamentals of embedded systems.
- Develop and test embedded C programs.
- Simulate microcontroller circuits using Proteus.
- Interface sensors and electronic components with Arduino.
- Learn basic communication protocols and real-time data acquisition.

## 🚀 How to Use

1. Clone or download this repository.
2. Open Keil µVision projects using the Keil software.
3. Open circuit design files using Proteus Design Suite.
4. Open Arduino sketches (`.ino`) using the Arduino IDE.
5. Compile, simulate, or upload the programs according to the experiment requirements.

## 📌 Note

The experiments are intended for educational purposes and practical learning as part of the Embedded Systems Laboratory.
